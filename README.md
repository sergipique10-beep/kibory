# Kibory

Landing de Kibory, comida real para perros. Sitio estático: `index.html`, `style.css` y `main.js`, sin dependencias.

- `img/` fotos de perros (recortes en WebP con transparencia).
- `fonts/` Bricolage Grotesque, Manrope y Caveat, alojadas en el propio sitio.
- La comida (croquetas, ingredientes, polaroids) se dibuja en canvas desde `main.js`.

Publicado en Render como Static Site (Publish Directory: `.`).
